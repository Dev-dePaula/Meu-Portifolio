Não é uma prova de conceito. É um banco digital Pix rodando com clientes reais, apps nas duas lojas e conformidade ativa com o Banco Central.

Voltz Pay + marca irmã Zait Pay — plataforma multi-tenant

Em produção

Plataforma de banking digital construída em torno do Pix, com apps web e mobile (Android/iOS). Arquitetei o sistema do núcleo bancário multi-tenant até a publicação dos aplicativos nativos nas lojas, conduzindo levantamento de requisitos, arquitetura, implementação, testes em produção e operação contínua.

  • Backend multi-tenant com isolamento de dados por núcleo de conta
  • RBAC completo: Master / Admin / Gerente / Cliente
  • Pix: envio, recebimento, QR Code dinâmico e estático
  • Split de pagamentos configurável
  • Limites diurno/noturno com carência de 24h (norma Bacen)
  • Verificação de destinatário em tempo real via DICT
  • Integração BaaS (Woovi/OpenPix) com reconciliação via webhooks
  • Notificações próprias: webhook de saída + e-mail transacional
  • KYC, biometria (Face ID/digital) e senha de transação
  • Expiração automática de sessão por inatividade
  • Apps nativos Android publicados via Capacitor + Play Console
  • CI/CD com GitHub Actions e sync seguro de schema (Prisma)
